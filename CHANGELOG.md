# Changelog

## 1.0.0 - Minecraft 26.3

First release.

- Timed backups based on play time
- Backup when leaving a world or stopping a server
- Manual backups from the pause menu, a key binding or `/eazybackup create`
- Per world retention limit, locked backups are never deleted
- Restore over the world or as a copy, with an automatic safety backup
- Backups of deleted worlds can still be restored
- Rename, lock, delete and open the folder of backups
- Options screen with Mod Menu support
- English and Brazilian Portuguese translations
